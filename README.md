# 家联

iPhone 上的家庭设备入口。打开后选择要关联的平台。关联小米、格力+、360 智慧生活、德业智能、远大空气管家、美的美居、海尔智家或 70 迈账号后，可以查看该账号下的设备。Jbotsports Pro 不使用云账号，靠近发球机后直接用蓝牙关联。

## 打开工程

需要 Mac 和 Xcode 16 或更新版本。

1. 打开 `HomeLink/HomeLink.xcodeproj`。
2. 选中 HomeLink target，在 Signing & Capabilities 里选你的 Apple ID。
3. 运行到真机或模拟器。米家控制走公网，模拟器也可以登录。

## 关联米家

推荐用扫码：另一台已登录米家的手机，打开米家或小米账号的扫一扫。也可以用账号密码。小米如果要求验证码或短信/邮箱验证，应用里会接着问。

地区要和账号注册地一致，大陆账号选「中国大陆」。密码只留在内存里向小米换会话，不会上传到别的服务器，也不会保存在手机里。登录成功后，钥匙串只保存会话。

米家没有面向第三方的完整官方授权，这里用的是和小米云直接通信的同一套登录与设备接口。控制指令发到小米云端，设备需要在线。

## Apple 家庭

可以把已经加入「家庭」的设备放在同一个列表里。免费 Apple ID 通常无法签名 HomeKit 能力；需要时在 Xcode 里打开 HomeKit，并用付费开发者账号签名。米家功能不依赖这项能力。

## 格力+

用格力+账号和密码登录，地区要和 App 里一致。设备按家庭、房间列出。空调可以开关，并调节模式、温度和风速。指令经过格力云端，设备需要在线。个别只走旧固件的空调可能列出来但不能控制。

## 360 智慧生活

用 360 账号登录。如果出现图形验证码，在应用里接着填写。同步的是这个账号在智慧生活云端返回的设备；扫地机器人可以开始清扫、暂停和回充。摄像头等其他品类会显示在线状态，各自的专用控制还不在这一版里。

## 德业智能

用德业智能的手机号和密码登录。新协议（Fog）的除湿机可以开关，并调节模式、目标湿度和风速。旧协议设备目前只能查看是否在线。

密码都只留在内存里换会话，不会保存，也不会发到这些厂商以外的服务器。登录成功后，钥匙串只保存会话。

## 远大空气管家

用远大空气管家的账号和密码登录。登录后同步这个账号下的设备，并显示是否在线。密码只留在内存里换会话。

## 美的美居

用美的美居的手机号和密码登录。设备按家庭和房间列出。读到开关状态的设备可以开关，指令发到美的云端，设备需要在线。

## 海尔智家

用海尔智家 App 的账号和密码登录。同步设备名称和在线状态。钥匙串只保存登录后的令牌和刷新令牌。各机型自己的细项控制还不在这一版里。

## 70 迈

用 70 迈账号登录。公开的云端接口在 `eu-api.70mai.com`，登录后列出这个账号下的记录仪。远程视频走记录仪自己的点对点通道，不在家联里播放。大陆账号如果登录失败，通常是账号不在这个站点。

## Jbotsports Pro

发球机没有云账号。打开机器并站在旁边，选中搜到的设备即可关联。开始和停止通过蓝牙直接发给这台机器，需要真机。

## 其他平台

霍曼宠物、华为智慧生活、涂鸦、绿米目前是适配位。霍曼宠物还没有稳定的公开登录接口。有稳定授权接口后，可以按现有的 `IoTHome` / `IoTDevice` 模型接进来。
