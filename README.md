# 家联

这是一份给自己用的 iPhone 实验工程，用来在本机上看已经加入 **Apple「家庭」** 的设备，以及身边通过蓝牙直接连上的设备。

## 建议怎么用

风险最低的用法只有两种：

1. **Apple 家庭（HomeKit）**  
   系统提供的接口。把已经加入「家庭」的灯、插座、传感器放进同一个列表。免费 Apple ID 通常签不出 HomeKit 能力；需要时在 Xcode 里打开 HomeKit，并用付费开发者账号签名。
2. **身边的蓝牙设备**  
   不经过厂商云。打开机器并站在旁边，选中搜到的设备即可关联。开始和停止由本机蓝牙发给这台机器，需要真机。目前接的是 Jbotsports Pro 发球机。

不要用本仓库去对接各家未开放的云账号，也不要把工程编译后发给别人装。

## 打开工程

需要 Mac 和 Xcode 16 或更新版本。仅供本机编译、本机安装。

1. 打开 `HomeLink/HomeLink.xcodeproj`。
2. 选中 HomeLink target，在 Signing & Capabilities 里选你的 Apple ID。
3. 运行到真机或模拟器。HomeKit 相关能力以真机和开发者签名为准。

密码如果在界面里出现过，只留在内存里换会话，不会写进本机存储，也不会发到这些厂商以外的服务器。登录成功后，钥匙串只保存会话。即便如此，也不应把未授权的云登录当作常规用法。
