# HomeLink

把家里已经在用的智能设备放到同一个 iPhone App 里看、搜、置顶，并按平台控制。界面是 SwiftUI，面向 iOS 17。

这是个人自用工程，**不是**各厂商官方客户端，也没有获得小米、格力、360、德业、远大、美的、海尔、70 迈等公司的授权或合作。品牌名只用来说明账号来源。云接口可能随时变化，使用官方账号即自行承担该服务用户协议下的后果。

## 能做什么

- 关联多个平台账号，按家庭 / 房间列出设备，支持搜索和下拉同步。
- 「全部设备」里可以把常用设备置顶，并调整置顶顺序。
- 打开设备详情后，按平台给出开关、模式、清扫等操作；没有公开控制口的设备至少能看名称和在线状态。
- 密码只用来换会话，不会写入本机存储。登录成功后，钥匙串只保存会话。

## 怎么用

1. 打开 App，在「平台」里选要关联的账号并登录。
2. 回到「全部设备」下拉同步。可按平台筛选，也可搜索设备名。
3. 点进设备进行控制。格力空调、米家设备、德业除湿机等会进入对应的详情页。
4. 控制会发到对应云端（或本机蓝牙 / HomeKit），设备需要在线。个别老固件仍可能只在官方 App 里响应。

免费 Apple ID 通常签不出 HomeKit 能力。真机若提示没有家庭权限，需要用付费开发者账号在 Xcode 的 Signing & Capabilities 里打开 HomeKit。米家等云平台关联不依赖这项能力。

## 打开工程

需要 Mac 和 Xcode 16 或更新版本。

1. 打开 `HomeLink.xcodeproj`。
2. 选中 HomeLink target，在 Signing & Capabilities 里选你的 Apple ID。
3. 运行到真机或模拟器。蓝牙发球机和 HomeKit 以真机为准。
